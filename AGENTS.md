## Working Style

- Keep solutions simple and incremental.
- Use current, stable APIs based on the project's declared dependencies.

## Python

- Use `uv` for dependency management, virtual environments, and running commands.
- Keep dependencies in `pyproject.toml`.

## Code Style

- Avoid overengineering.
- Prefer short modules and functions with clear names.
- Write self-explanatory code without unnecessary comments.
- Use exceptions only when they add value.

## Debugging

- Find the root cause before fixing.
- Validate one change at a time.

## Testing

- Rely on automated tests (unit and integration).
- Run tests through `uv`.

## Language

- Use English for all code identifiers.
- Use Portuguese only for user-facing text.
